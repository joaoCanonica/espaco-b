Sessão 5, acesso em **13/10/2026**.

**Limite deste ambiente:** a busca na web funcionou, mas a leitura integral das páginas falhou. O `WebFetch` deu falha de DNS para todos os domínios testados (coffito.gov.br, in.gov.br, pubmed, abmes), e o `curl` foi barrado pelo proxy (403). Por isso cada fonte abaixo foi lida **pelo trecho citado no resultado do buscador**, não pelo documento inteiro. Onde isso importa, o arquivo diz **"não consegui verificar o texto integral"** e como verificar.

**Níveis de evidência usados:**

- **N1:** norma oficial (DOU, resolução, acórdão) ou revisão sistemática/meta-análise publicada.
- **N2:** ensaio clínico, estudo observacional grande ou documento oficial de conselho regional.
- **N3:** notícia, cartilha, blog de conselho ou associação.
- **N4:** material de fabricante, clínica ou marketing. Só serve como pista.

Quando o nível vem com "(trecho)", a fonte foi lida só pelo trecho do buscador.
